
# Deepak Dhatterwal - Official Actor Portfolio Website

Production-grade cinematic portfolio website built for **Deepak Dhatterwal** (Indian Actor & Performer). 

Deployed Live At: [https://deepak-dhatterwal.vercel.app/](https://deepak-dhatterwal.vercel.app/)

## Tech Stack
- **Frontend**: HTML5, CSS3, ES6+ Vanilla JavaScript
- **Frameworks & UI**: Bootstrap 5, Font Awesome 6, Bootstrap Icons
- **Animations**: AOS Library, Swiper.js
- **Form Engine**: FormSubmit (Serverless Contact Delivery)
- **Deployment**: Vercel Ready
